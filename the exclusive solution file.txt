  → window separation যাচাই যোগ করা হলো

BUG ২ — credential check সাধারণ path-কে credential ভাবত
  "live/zee_bangla_abr/live/zee_bangla_720" ৪০+ অক্ষর ও digit আছে, কিন্তু
  প্রতিটি segment ছোট শব্দ। length test এখন **segment**-এ, পুরো run-এ নয়।

BUG ৩ — redacted parameter-কেও leak ভাবত
  "?token={redacted}" — মান আগেই placeholder, তবু parameter-এর **নাম** দেখে
  fire করত। ফলে Zee Bangla scout-এর পুরো report withheld হয়ে গিয়েছিল।
  → placeholder-যুক্ত parameter বাদ দিয়ে তারপর check

  BUG ২ ও ৩ একসাথে তৃতীয়বার এই check-কে বৈধ report ধ্বংস করতে দেখল, তাই
  ৯টি case দিয়ে দুই দিকেই বাঁধা হয়েছে — সাধারণ path ও redacted parameter
  পাশ করে, আসল credential ও ছোট token ধরা পড়ে।

BUG ৪ — আমার নিজের test-এ `float(stall or 99)`
  stall শূন্য হলে Python `0 or 99` = 99 ধরে, অর্থাৎ সেরা ফলকে সবচেয়ে খারাপ
  পড়ত। → explicit None check। পুরো repository-তে একই ভুল আর নেই, যাচাই করা।
