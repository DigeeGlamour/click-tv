Scanner cadence-এর সমাধান (§২ কারণ ২ ও ৩) push করা যায়নি:

    ! [remote rejected] main -> main
      refusing to allow a Personal Access Token to create or update workflow
      `.github/workflows/scan.yml` without `workflow` scope

আপনার মেশিনে সংরক্ষিত GitHub token-এ `workflow` scope নেই, তাই
.github/workflows/ ছোঁয়া কোনো commit push করা যাচ্ছে না — main-এ বা অন্য
branch-এ, কোথাওই নয়। এটি নিরাপত্তা নিয়ম, ভুল নয়।

commit-টি তৈরি ও পরীক্ষিত হয়ে আছে (357005bda) — local branch
`workflow-catchup`-এ, আর patch ফাইল হিসেবেও:

    c:\Users\RUMAN\Downloads\Click Tv analysis\workflow-catchup.patch

তিনটি উপায়ের যেকোনো একটি:

  (ক) Token-এ scope দিন (সবচেয়ে সহজ)
      github.com/settings/tokens → আপনার token → `workflow` টিক দিন → update।
      তারপর:
          cd "c:\Users\RUMAN\Downloads\Click Tv analysis\repo"
          git checkout main
          git cherry-pick 357005bda
          git push origin main

  (খ) Patch নিজে apply করুন
          git checkout main
          git am "..\workflow-catchup.patch"
          git push origin main

  (গ) GitHub-এর web editor-এ .github/workflows/scan.yml সম্পাদনা করুন
      (browser থেকে করলে token scope লাগে না)। তবে (ক) বা (খ) সহজ, কারণ
      commit-টিতে scripts/select-scan-mode.py ও দুটি test ফাইলও আছে যেগুলো
      ছাড়া test suite fail করবে — অর্থাৎ চারটি ফাইল একসাথেই যেতে হবে।

এটি না গেলে: channels ও movies scan আগের মতোই বেশিরভাগ সময় চলবে না, এবং
test suite প্রতি CI run-এ route-persistence ledger মুছতে থাকবে।
