--------------------------------------------------------------------------------
মূল সিদ্ধান্ত (আপনার Option C)
--------------------------------------------------------------------------------
ম্যাচ শুরুর ৩০ মিনিট আগেই Today Match-এ চলে আসবে।

কেন এটা ঠিক:
  ৭:৪৫-এ সাইট খুলে "Today Match" চাপলে ৮টার ম্যাচ নেই — এটা সত্যিকারের ভুল।
  নাম বদলে ("Live Now") সেটা সারে না। এটা নাম নয়, আচরণ ঠিক করে।
  আর Upcoming-এ ২১০টা, Today-তে ২৭টা — যেগুলো এখনই দরকার সেগুলো Today-তে
  এলে দুটো tab-ই নিজের কাজটা করবে।

নতুন প্রবাহ:
  ৩০ মিনিটের বেশি বাকি  →  Upcoming
  ≤ ৩০ মিনিট বাকি       →  Today Match  🟡 শুরু হবে ২৮ মিনিট পর
  link পাওয়া গেল        →  Today Match  🟢 stream প্রস্তুত • ১২ মিনিট পর
  শুরু হয়ে গেছে         →  Today Match  🔴 LIVE
  শুরু হয়েছে, link নেই   →  Today Match  🟠 link খোঁজা হচ্ছে
  ৩০ মিনিট পরেও link নেই →  বাদ

  Upcoming → Starting Soon → Live Now → Ended
  card কোথাও অদ্ভুতভাবে লাফাবে না।

কাজের তালিকা
================================================================================

[✅ শেষ]  ১. খোঁজার জানালা ২০ → ৩০ মিনিট
--------------------------------------------------------------------------------
    কেন ৩০: routing threshold-ও ৩০। ২০ থাকলে card ৩০ মিনিটে Today-তে আসত
    কিন্তু link খোঁজা শুরু হত ১০ মিনিট পরে — ওই ১০ মিনিট card বসে থাকত।

    config/settings.json → targeted_window_minutes: 30
    আসল scan-এ প্রমাণ:
      "Targeted window: -30 minutes; targets=3, outside window=207"


[  বাকি]  ২. Routing — ৩০ মিনিট বাকি থাকতেই Today Match-এ
--------------------------------------------------------------------------------
    এখন: STARTING_SOON আর LINK_UPDATING → Upcoming
    হবে : সময় ≤ ৩০ মিনিট হলে status যাই হোক → Today Match

    গুরুত্বপূর্ণ: এখনকার targeted_window_minutes শুধু "link খোঁজার" জানালা,
    tab routing-এর নিয়ম নয়। তাই routing-এর জন্য আলাদা নিয়ম লাগবে।

    ফাইল: scanner/event_lifecycle.py → event_destination()


[  বাকি]  ৩. Today card-এ status + countdown
--------------------------------------------------------------------------------
    ⚠️ এখানে আমার আগের পরামর্শ উল্টে যাচ্ছে, সেটা লিখে রাখলাম।

    আমি বলেছিলাম "Today-তে সবই live, তাই badge আবর্জনা"।
    কিন্তু Today-তে এখনো শুরু না হওয়া ম্যাচ ঢুকলে status ছাড়া card
    মিথ্যা বলবে — দেখতে live লাগবে, আসলে নয়। তাই এখন লাগবেই।

      🔴 LIVE
      🟡 শুরু হবে ১২ মিনিট পর
      🟠 link খোঁজা হচ্ছে

    ফাইল: site/assets/js/app.js → createTodayMatchCardV2()


[  বাকি]  ৪. Today-র ভেতরে সাজানো
--------------------------------------------------------------------------------
    LIVE আগে → তারপর STARTING_SOON → তারপর সময় অনুযায়ী
    নইলে না-শুরু-হওয়া ম্যাচ চলতি ম্যাচের উপরে বসবে।


[  বাকি]  ৫. Header-এর লেখা
--------------------------------------------------------------------------------
    "27 Live" আর সত্যি থাকবে না → "27 Matches • 5 Live"


[  বাকি]  ৬. link না এলে বাদ দেওয়া
--------------------------------------------------------------------------------
    শুরুর ৩০ মিনিট পরেও কোনো source link না দিলে Today থেকে বাদ।
    তার বেশি রাখলে Today-ও আবর্জনায় ভরবে।

    (এখনকার নিয়ম ১০ মিনিট, কিন্তু সেটা Upcoming থেকে বাদ দেওয়ার নিয়ম।
     নতুন system-এ card তখন Today-তে থাকবে, তাই নিয়মটা সরাতে হবে।)


[  বাকি]  ৭. Upcoming-এর sort — যেটা আগে শুরু হবে
--------------------------------------------------------------------------------
    এখন যা হচ্ছে:
      ৫ মিনিট পরে football   ← নিচে
      আগামীকালের cricket     ← উপরে

    কারণ কোডে sportRank সময়ের আগে চলে (app.js line ~1841)।

    দুই tab-এ দুই নিয়ম:
      Today    → cricket আগে (সবই live, বাংলাদেশে cricket-ই আগে)
      Upcoming → যেটা আগে শুরু হবে (সময়ই এখানে একমাত্র যুক্তি)


[  বাকি]  ৮. মোবাইলে tap target ২৫px → ৪০px
--------------------------------------------------------------------------------
    এখন: min-height 25px, font-size 9.5px  (৪৬০px-এর নিচে)
    Apple বলে ৪৪px, Android ৪৮dp — অর্ধেকেরও কম।
    খেলার মাঝে ভুল ট্যাপে stream বদলে যাওয়া সত্যিকারের বিরক্তি।

    সাবধানে: ২ column grid-এ button বড় করলে জায়গা কমে।
    তাই ৪২০px-এর নিচে channel strip এক column — লেখা আরও ছোট করার চেয়ে।

    ফাইল: site/assets/css/event-channel-cards.css


[  বাকি]  ৯. এক-channel card-এ channel-এর নাম
--------------------------------------------------------------------------------
    এখন ২টার কম channel হলে strip পুরো লুকানো থাকে।
    কিন্তু Willow / Willow 2 / Sony-র মান আলাদা — কোনটা পাচ্ছি জানা দরকার।


[  না করা]  ১০. নাম বদলে "Live Now"
--------------------------------------------------------------------------------
    ❌ করা হবে না।
    পাশেই header-এ "27 Live" লেখা থাকে — সত্যিটা পর্দাতেই আছে।
    খরচ আছে: পুরোনো ব্যবহারকারীর অভ্যাস, PWA-র নাম, bookmark।
    আর "Today Match" বাংলা খেলার সাইটে চেনা শব্দ, "Live Now" নয়।

    Audit-এর আসল দুশ্চিন্তা ছিল "৩০ মিনিট পরের ম্যাচ কোথায়?" —
    সেটার সমাধান নাম বদলানো নয়, ২ নম্বর কাজটা।
