সবচেয়ে বড় আবিষ্কার: bd-mc-flive বাংলাদেশে বন্ধ নয়
--------------------------------------------------------------------------------
Google CDN তিনটে আলাদা উত্তর দেয়, আর সেটাই সব বলে দেয়:

  bd-mc-flive,  token ছাড়া    →  "Unsigned request rejected"   Error 94
  bd-mc-flive,  ভুল token      →  "Invalid signed request"      Error 98
  bd-mc-flive,  feed-এর token  →  "Invalid signed request"      Error 98

  in-mc-flive,  token ছাড়া    →  "forbidden"                   Error 7
  in-mc-flive,  ভুল token      →  "forbidden"                   Error 7
  in-mc-flive,  feed-এর token  →  "forbidden"                   Error 7

`in-` token দেখেই না — অঞ্চল দেখে মানা করে।
`bd-` signature পড়ে, যাচাই করে, তারপর বলে "এটা ঠিক নয়"।

মানে BD CDN আমাদের দিতে রাজি। শুধু ওই host-এর জন্য বানানো signature চাই।

সমর্থক প্রমাণ: response header-এ `x-client-region: BD` — CDN জানে আমরা
বাংলাদেশে। আর FanCode-এর `helpdesk.fancode.com/bd/` পাতা আছে, তাই
বাংলাদেশ তাদের স্বীকৃত অঞ্চল।

তাহলে আটকাচ্ছে কী
--------------------------------------------------------------------------------
সব public feed ভারতে বানানো token প্রকাশ করে।

GitHub-এ "bd-mc-flive.fancode.com" খুঁজে ৮টা repo পেয়েছি। সবগুলো পরীক্ষা করেছি।
যেগুলো "BD" নামে চালায়, তারা শুধু host-এর নাম বদলে দেয় — signature ভারতেরই:

  match 139965   BD feed: ARB3KG1uT-VgHvpr6I   IN feed: ARB3KG1uT-VgHvpr6I  একই
  match 4248358  BD feed: ARB3KG0f4aommq75Ho   IN feed: ARB3KG0f4aommq75Ho  একই
  match 4248584  BD feed: ARB3KG3b8eg1E7i9lY   IN feed: ARB3KG3b8eg1E7i9lY  একই

আর token-এর মেয়াদ শেষ নয় — ৯৮৫ থেকে ১৩৬৫ মিনিট বাকি ছিল।
তাই মেয়াদ, header, user-agent — কোনোটাই কারণ নয়।

================================================================================
অংশ ২ — TOKEN কোথা থেকে আসে: যতদূর গেছি
================================================================================
আপনি বলেছিলেন Worker বানানোর আগে প্রমাণ করতে কোন request token বানায়।
সেটাই করার চেষ্টা করেছি।

যা পেয়েছি:
  • FanCode-এর API: https://www.fancode.com/graphql  (POST, Apollo Server)
  • `{__typename}` → HTTP 200, কাজ করে
  • introspection বন্ধ
  • field খুঁজে পেয়েছি: match(id: Int!) এবং media(id: Int!) এবং tour(collectionId: Int!)
  • Match type-এ আছে: id, name, status
  • Match type-এ নেই: streamingUrl, playbackUrl, videoUrl, hlsUrl, stream,
    playback, source, cdn, token — কোনোটাই না
  • ওই match_id দিলে Query.match null ফেরত দেয়

যা পারিনি:
  • Browser দিয়ে fancode.com-এ live ম্যাচ চালিয়ে network trace — পাতাটা
    SPA, home page-এ /match/ link খুঁজে পায়নি, ০টা request ধরা পড়েছে।
    এটা করা বাকি আছে, এবং এটাই পরের ধাপ।

⚠️ তাই এখনো প্রমাণ হয়নি কোন request token বানায়।
   আপনার নির্দেশ মেনে কোনো Worker/proxy বানাইনি।
